# Autocheck — Микросервис интеграции с автосалонами (1С Парсер)

MVP асинхронного сервиса для приема, парсинга и синхронизации выгрузок складских остатков автомобилей из 1С в базу данных автосалона.

---

## 🛠 Стек технологий

- **Язык**: Python 3.11+
- **Фреймворк**: FastAPI (Pydantic v2)
- **База данных**: SQLAlchemy 2.0 (Asyncio) + aiosqlite (SQLite) / поддержка PostgreSQL
- **Фоновые задачи**: APScheduler (`AsyncIOScheduler`)
- **Контейнеризация**: Docker, Docker Compose
- **Интерфейс**: Jinja2, HTML5/CSS3 (Glassmorphism), Vanilla JS
- **Тестирование**: Pytest, pytest-asyncio, HTTPX

---

## 🚀 Быстрый запуск

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

```bash
docker compose up --build
```

Сервис запустится и будет доступен по адресам:
- **Веб-интерфейс каталога**: [http://localhost:8000](http://localhost:8000)
- **Swagger / OpenAPI UI**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **Альтернативная документация ReDoc**: [http://localhost:8000/redoc](http://localhost:8000/redoc)

### Вариант 2: Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Запуск приложения
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## 🔍 Проверка условий ТЗ

### 1. Проверка логики Upsert (Вставка и обновление по VIN)

Уникальным идентификатором автомобиля является его **VIN-номер (17 символов)**.

Проверить работу Upsert можно прямо из веб-интерфейса или через API:

1. **Шаг 1 (Базовое состояние):**
   - Нажмите кнопку **«Импортировать базовые 10 авто»** в блоке управления выгрузками.
   - Загружаются 10 автомобилей из `data/1c_dump_base.json` (например, Toyota Camry с ценой 15 200 000 ₸).
   - Тост покажет: `Создано: 10, Обновлено: 0`.

2. **Шаг 2 (Применение обновления):**
   - Нажмите кнопку **«Применить обновление (Upsert)»** (`data/1c_dump_update.json`).
   - У 5 существующих авто обновятся цена и пробег (цена на Camry снизится до 14 400 000 ₸ со скидкой), и добавятся 2 новые машины (Audi Q5, Range Rover Sport).
   - Тост покажет: `Создано: 2, Обновлено: 5`.

3. **Шаг 3 (Сброс базы):**
   - Кнопка **«Сбросить базу (10 авто)»** (`POST /api/reset`) полностью очищает таблицу и восстанавливает начальные 10 автомобилей.

### 2. Поддержка форматов JSON и CSV

- **CSV с разделителем `;`**: Нажмите **«Импортировать CSV (5 авто)»** (`data/1c_dump_partner.csv`) — сервис автоматически распознает структуру и разделители.
- **Ручная загрузка**: Кнопка **«Загрузить свой JSON/CSV»** отправляет произвольный файл на эндпоинт `POST /api/upload`.

## 📦 Тестовые наборы данных (`data/`)

Все цены приведены в казахстанских тенге (**₸**) в соответствии с рынком РК:

| Файл | Содержимое | Назначение |
|---|---|---|
| `data/1c_dump_base.json` | 10 авто (Camry, Tucson, Sportage, Vesta, Solaris, K5, Prado, RX 350, BMW 5, Granta) | Исходный базовый каталог |
| `data/1c_dump_update.json` | 7 авто (5 обновлений цен/пробега + 2 новых авто) | Наглядная проверка логики Upsert |
| `data/1c_dump_partner.csv` | 5 авто (BMW X5, Touareg, Forester, Elantra, RAV4) | Проверка поддержки CSV-файлов |
| `data/1c_dump.json` | 16 авто полного диапазона | Файл для периодического фонового парсинга |

## 🔌 REST API Маршруты

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/` | Веб-интерфейс каталога с фильтрацией и панелью управления дампами |
| `GET` | `/api/cars` | Список авто с фильтрами (`mark`, `search`, `min_year`, `max_year`, `min_price`, `max_price`) |
| `GET` | `/api/cars/{vin}` | Детальная карточка автомобиля по VIN |
| `POST` | `/api/sync` | Запуск синхронизации (параметр `?file_name=...` для выбора файла из `data/`) |
| `GET` | `/api/dumps` | Список доступных файлов выгрузок на сервере |
| `POST` | `/api/upload` | Загрузка и немедленный парсинг произвольного файла (JSON/CSV) |
| `POST` | `/api/reset` | Полная очистка БД и инициализация 10 базовыми авто |
| `DELETE` | `/api/cars` | Алиас сброса каталога |
| `GET` | `/api/status` | Статус сервиса, БД и время последней синхронизации (Asia/Almaty) |

## 🧪 Запуск автотестов

Набор тестов запускается в изолированной SQLite in-memory базе:

```bash
pytest tests/ -v
```

Покрыты сценарии:
- Нормализация русских ключей 1С (`Марка`, `Модель`, `Год`, `Цена` и т.д.).
- Парсинг CSV с различными разделителями (`;`, `,`).
- Логика атомарного Upsert (Insert + Update).
- Проверка локального времени без сдвига UTC (Asia/Almaty).
- Обработка пустых строк в параметрах поиска без ошибки 422.
- Эндпоинты API, сброс базы данных (`/api/reset`) и загрузка файлов.
