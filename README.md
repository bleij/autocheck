# Autocheck — Микросервис интеграции и парсинга выгрузок 1С

Асинхронный микросервис на **FastAPI** для приема, парсинга и периодической синхронизации данных об автомобилях из выгрузок **1С** (форматы JSON и CSV). Поддерживает операцию **Upsert** (вставка новых записей и обновление существующих по уникальному ключу `VIN`), фоновый планировщик задач **APScheduler**, сохранение в **SQLAlchemy (Async)** и современный веб-интерфейс на **Jinja2**.

### Вариант 1. Запуск через Docker Compose (Рекомендуемый)

Для моментального развертывания со всеми зависимостями:


- **Веб-интерфейс каталога**: [http://localhost:8000/](http://localhost:8000/)

- **Альтернативная документация ReDoc**: [http://localhost:8000/redoc](http://localhost:8000/redoc)

```bash
docker compose down
```

## 🔄 Логика парсинга и Upsert

1. **Гибкость полей 1С**: Сервис автоматически распознает как русские названия полей (`VIN`, `Марка`, `Модель`, `Год`, `Пробег`, `Цена`, `Дефекты`), так и стандартные латинские названия.
2. **Атомарный Upsert**:
   - При парсинге файл считывается батчами.
   - По уникальному 17-значному идентификатору `vin` система проверяет наличие автомобиля в базе.
   - Если автомобиль уже есть в базе — актуализируются его стоимость, пробег, описание дефектов и дата обновления `updated_at`.
   - Если автомобиль новый — создается новая запись.
   - Дубликаты внутри одного файла объединяются (приоритет у последней записи).
3. **Форматы выгрузки**:
   - `JSON`: массив объектов либо объект с корневыми ключами (`cars`, `items`, `Выгрузка`, `Автомобили`).
   - `CSV`: автоматическое определение разделителя (запятая или точка с запятой), поддержка кодировок UTF-8 и CP1251 (Windows).

## ⏰ Фоновый планировщик (APScheduler)

В приложение встроен асинхронный планировщик `AsyncIOScheduler`:
- Периодически (по умолчанию каждые **5 минут**, настраивается параметром `PARSE_INTERVAL_MINUTES`) считывает актуальный файл по пути `data/1c_dump.json`.
- Автоматически синхронизирует базу данных без перезапуска сервиса.
- Если автосалон обновил файл на диске, новые цены и автомобили подтянутся в каталог автоматически.

## 🔌 REST API Маршруты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/` | Главная HTML-страница каталога с фильтрацией и статистикой |
| `GET` | `/api/cars` | Получить список автомобилей (фильтры `mark`, `search`, `min_year`, `max_price`, пагинация `limit`, `offset`) |
| `GET` | `/api/cars/{vin}` | Получить детальную информацию об автомобиле по VIN |
| `POST` | `/api/sync` | Принудительный запуск синхронизации локального файла выгрузки |
| `POST` | `/api/upload` | Ручная загрузка нового файла (JSON/CSV) через `multipart/form-data` |
| `GET` | `/api/status` | Статус здоровья сервиса и результат последней фоновой синхронизации |

## 🧪 Запуск тестов

Для запуска набора автоматических тестов (unit + integration):

```bash
pytest tests/ -v
```

Тесты выполняются в изолированной `in-memory` базе SQLite и проверяют:
- Парсинг русских ключей 1С.
- Парсинг CSV с различными разделителями.
- Корректность вставки и обновления записей (upsert).
- Работу всех HTTP API эндпоинтов и возврат HTML-страницы.
